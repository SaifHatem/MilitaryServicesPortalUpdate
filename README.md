# منظومة الخدمات المقدمة للسادة ضباط هيئة الإستخبارات العسكرية

## المتطلبات
- Node.js 22 LTS (أو Node.js 20.19 فأحدث).
- MongoDB Community Server مثبت ويعمل محليًا.
- اتصال إنترنت أول مرة فقط لتنزيل حزم npm.

## أول تشغيل على Windows
1. فك ضغط المشروع.
2. شغّل `Start-Portal.bat`.
3. في أول تشغيل، سيُنشأ `backend/.env` من الملف النموذجي ويفتحه Notepad.
4. تأكد من `MONGO_URI` وأن `JWT_SECRET` قيمة طويلة وعشوائية، واحفظ الملف.
5. تأكد أن خدمة MongoDB تعمل، ثم نفّذ `npm run seed` لمزامنة الخدمات والمتطلبات الجديدة.
6. نفّذ سكريبت إعادة ضبط حسابات الضباط إذا كنت تريد البدء بحسابات جديدة (التفاصيل بالأسفل).
7. شغّل `Start-Portal.bat` مرة أخرى؛ سيبني الواجهة ويشغّل الـ Backend ويفتح `http://localhost:1234`.

## التشغيل اليدوي
من داخل مجلد المشروع:

```bash
npm install --prefix backend
npm install --prefix frontend
npm run build
npm start
```

للتطوير، شغّل الـ Backend والـ Frontend في نافذتين منفصلتين:

```bash
npm run dev:backend
npm run dev:frontend
```

## إعداد MongoDB
القيمة الافتراضية في `backend/.env.example`:

```env
MONGO_URI=mongodb://127.0.0.1:27017/military_services
PORT=1234
JWT_SECRET=replace_this_with_a_long_random_secret
```

لا تشارك ملف `backend/.env` أو ترفعه إلى Git لأنه يحتوي على إعدادات سرية.

## تهيئة الخدمات والمتطلبات
بعد تشغيل MongoDB وضبط `backend/.env`، يمكن مزامنة الخدمات والمتطلبات:

```bash
npm run seed
```

الـ seed الحالي يعمل بطريقة upsert ولا يحذف الخدمات أو المتطلبات أو الطلبات الموجودة.

## إعادة ضبط حسابات الضباط التجريبية
السكريبت يحذف حسابات الضباط ذات الدور `user` وطلبات كل حساب وملفاتها المرفوعة. يحتفظ بحسابات `admin` و`reviewer`.

من Command Prompt:

```bat
set CONFIRM_DELETE_TEST_USERS=YES
npm run reset:users
```

لا تشغّل الأمر إلا بعد التأكد من قاعدة البيانات المستهدفة. لا يتم تنفيذ الحذف تلقائيًا عند تشغيل المشروع.

## فيديو صفحات الدخول
ضع فيديو الخلفية باسم:

`frontend/public/videos/auth-background.mp4`

ويظهر تلقائيًا في تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور. عند استبداله، احتفظ بنفس الاسم ثم نفّذ `npm run build`.

## بيانات ترخيص السلاح
ملفات PDF الافتراضية موجودة في:

`frontend/public/guides/weapon-license/`

يوجد ملف مستقل لكل متطلب باسم `requirement-01.pdf` حتى `requirement-09.pdf`:

1. `requirement-01.pdf` — تحقيق الشخصية العسكرية.
2. `requirement-02.pdf` — رقم الهاتف.
3. `requirement-03.pdf` — البطاقة الشخصية.
4. `requirement-04.pdf` — الالتماس الموجه لمدير أمن المحافظة.
5. `requirement-05.pdf` — إقرار عدم استخراج ترخيص إضافة.
6. `requirement-06.pdf` — إقرار العنوان المدني.
7. `requirement-07.pdf` — شهادة شئون الضباط لترخيص السلاح.
8. `requirement-08.pdf` — صورة توريد مبلغ 105 جنيه.
9. `requirement-09.pdf` — شهادة إعفاء السلاح المرخص من قبل.

استبدل كل ملف بالبيان المعتمد الخاص بالمتطلب المقابل مع الاحتفاظ باسم الملف نفسه، ثم أعد بناء الواجهة. روابط البيانات تظهر فقط في متطلبات خدمة ترخيص السلاح.

## ملاحظات صلاحيات المراجع
زر «إخفاء من قائمتي» يخفي الطلب للمراجع الحالي فقط. لا يحذف الطلب ولا ملفاته، ولا يؤثر على حساب صاحب الطلب أو على قائمة المراجعين الآخرين. حسابات Admin تحتفظ برؤية جميع الطلبات.
